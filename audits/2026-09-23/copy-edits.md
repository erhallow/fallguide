# Fall Guide — suggested copy edits

**Editorial review: September 23, 2026. None of these edits has been applied.**

[Prioritized report](./report.md) · [Complete link inventory](./link-audit.md)

This document covers the overview, navigation, signup copy, events and markets, community trick-or-treat list, haunts, town hours, farms, hikes, checklist, and footer. It concentrates on changes; wording without a recommendation can generally stay, subject to the source checks in the link inventory.

**Important:** A suggested sentence is not a substitute for verifying its supporting details. “Confirm” and “hold” mean the facts are not ready to publish as settled. Link IDs below correspond to the complete inventory. Keep the guide's warm, local voice; the goal is clearer planning information, not a generic directory.

## 1. Site-wide writing standards

| Issue | Suggested standard |
| --- | --- |
| Date styles vary: Sep / Sept, leading zeros, compact multi-month badges | Use “Sept. 25” and “Oct. 3.” For a span, write “Sept. 19–Oct. 25”; for repeated days, add “Fridays–Sundays.” Never imply continuous daily opening for weekend events. |
| Time labels are missing or ambiguous | Use “11:30 a.m., 1:30 p.m., 3:30 p.m., and 5:30 p.m.” or consistent compact equivalents. Add a visible Central Time note, while checking each source for exceptions. |
| Slashes hide what prices mean | “$15 advance / $20 day of show,” “$4 child / $8 adult,” or “$15.99 general admission / $25.99 all-access.” Preserve exact source age bands. |
| Free can mean several things | Distinguish “Free admission; activities extra,” “Free entry; food and drinks sold separately,” and “Free with registration.” Do not infer attendee admission from a vendor application. |
| Place names are inconsistent | Use “Valparaiso” and “La Porte” in structured location fields and the main listing details. “Valpo” is fine in casual narrative, but avoid alternating it with the full name within one row. Preserve an organizer's official brand spelling. |
| A badge appears to verify the whole card | Use “2026 dates confirmed,” “2026 details not verified,” or “2025 reference only.” Show separate notes for prices, availability, and hours. |
| Unsupported superlatives | Replace “biggest,” “best,” “one of the cleanest,” and “one of the country's last” with specific, sourced qualities unless you can support the comparison. |
| Relative time goes stale | Replace “Open now,” “last year,” and “last listed” with exact dates/years where known. “Last year” becomes misleading if the guide stays online into 2027. |
| Duplicates diverge | Reuse one record for the same event in different sections. Match dates, venue, price, age rules, and verification status. |
| Links are only an organization name | Use descriptive labels: “Sunset Hill Farm Trunk-or-Treat,” “Associated Pediatricians Trunk-or-Treat,” “Official event details,” or “Trail map (PDF).” |

For a standard event, aim for this order:

**Event name · Date**  
Time · Venue, town  
Admission and relevant age/registration rules  
One useful sentence about the experience  
Official details · Verification year/date

Use the same order even when a field is unknown: “Time not yet verified” is better than a confident date with no explanation.

## 2. Opening section and navigation

### Title and introduction

The main “Fall Guide 2026” title works. Consider adding the region to the accessible/page title:

> **Northwest Indiana Fall Guide 2026**
>
> Find pumpkin patches, fall festivals, Halloween events, and colorful hikes—all in one local guide from NWI Explored.

This replaces the overbroad “one-stop shop for everything fall” and immediately connects the guide to the newsletter.

Replace the long notice, especially the assurance that historical details are marked everywhere:

> **Before you go**
>
> Dates, hours, prices, and picking conditions can change. Check each listing's year and verification note, then visit the organizer's link before making plans. Information labeled “2025 reference only” is not a confirmed 2026 schedule.

Only use this once the per-listing labels are actually consistent. Until then, fix the affected cards rather than relying on a disclaimer to cover inaccurate details.
